#### Thì quá khứ hoàn thành
- structure
    - dùng [to have] là trợ động từ
        - [+] S + had + V3 + ..
        - [-] S + had + not + V3 + ..
        - [?] (wh) + had + S + V3 + ..

- dấu hiệu nhận biết:
    1. thì quá khứ hoàn thành thường đi với thì quá khứ đơn
- note
    1. Dạng viết tắt: I'd/he'd/she'd/It'd/we'd/you'd/they'd + gone out.
